# 🏪 چی داری؟

اپلیکیشن اندروید برای پیدا کردن **نزدیک‌ترین فروشگاه‌ها و خدمات** با GPS، مشاهده «پیج» فروشندگان، و **مقایسه قیمت** بین فروشگاه‌ها.

**Kotlin + Jetpack Compose + Room + Supabase Auth** — کاملاً فارسی و راست‌به‌چپ.

## 🔐 حساب کاربری (Supabase + SMTP جیمیل)

### دسترسی‌ها

| کار | مهمان | کاربر واردشده |
|---|:---:|:---:|
| دیدن فروشگاه‌ها و محصولات | ✅ | ✅ |
| جست‌وجو و مقایسه قیمت | ✅ | ✅ |
| تماس و مسیریابی | ✅ | ✅ |
| ❤️ افزودن به علاقه‌مندی | ❌ | ✅ |
| ➕ فالو کردن فروشگاه | ❌ | ✅ |
| 🏪 ساخت فروشگاه | ❌ | ✅ |
| ⭐ امتیاز دادن | ❌ | ✅ |

وقتی مهمان روی قلب یا دکمه فالو بزند، پیام راهنما می‌بیند و صفحه ورود باز می‌شود — بدون اینکه از صفحه فعلی پرت شود.

### امکانات احراز هویت
- ثبت‌نام و ورود با **ایمیل و رمز عبور**
- **تأیید حساب با کد عددی** (نه لینک) — چون لینک ایمیل روی گوشی باز نمی‌شود.
  طول کد هرچه باشد (۶ یا ۸ رقم) پذیرفته می‌شود.
- **بازیابی رمز عبور کامل**: کد ایمیل ← نشست موقت ← رمز تازه ← ورود خودکار
- نشست ماندگار با **تمدید خودکار توکن**
- خطاهای سرور به **پیام فارسی قابل فهم** ترجمه می‌شوند

### ⚙️ راه‌اندازی

برنامه بدون تنظیمات هم اجرا می‌شود (حالت مهمان). برای فعال کردن ثبت‌نام:

**راهنمای کامل در فایل [`SUPABASE_SETUP.md`](SUPABASE_SETUP.md) است** — شامل ساخت پروژه، گرفتن کلیدها، و تنظیم SMTP جیمیل با App Password.

خلاصه: دو مقدار را در `app/src/main/java/ir/chidari/data/auth/SupabaseConfig.kt` بگذارید:

```kotlin
const val URL: String = "https://xxxxx.supabase.co"
const val ANON_KEY: String = "eyJhbGciOi..."
```

## ⚡ بهینه‌سازی سرعت

نسخه قبلی با ۱۵۵۰ محصول کند بود. علت‌ها پیدا و رفع شدند:

| مشکل | راه‌حل | نتیجه |
|---|---|---|
| **حلقه O(n²)** — برای هر کالا کل فهرست پیمایش می‌شد تا «در چند فروشگاه هست» را بشمارد (~۲.۴ میلیون عملیات در هر بار رسم) | کوئری `GROUP BY` در SQL، جست‌وجوی O(1) در UI | **بزرگ‌ترین منبع کندی حذف شد** |
| هر حرف تایپ یک کوئری کامل می‌زد | `debounce(250ms)` روی جست‌وجو (بقیه فیلترها بی‌درنگ) | کوئری‌ها ~۹۰٪ کمتر |
| بدون سقف نتایج | `LIMIT` روی کوئری‌ها (۳۰۰ فروشگاه / ۴۰۰ محصول) | حافظه و زمان رسم کمتر |
| ~۱۸۵۰ درج جداگانه در اولین اجرا | همه در **یک تراکنش** | اجرای اول بسیار سریع‌تر |
| ایندکس ناقص | ایندکس ترکیبی روی `(province, city)`، `(storeId, category)`، `price`، `rating` | جست‌وجوی سریع‌تر |
| علاقه‌مندی‌ها از فهرست جاری فیلتر می‌شد | کوئری `JOIN` مستقیم | هم درست‌تر، هم سریع‌تر |
| `distinctUntilChanged` نبود | اضافه شد | رسم‌های تکراری حذف شد |

## ✨ بقیه امکانات

**موقعیت‌یابی:** Fused Location گوگل با بازگشت خودکار به سرویس سیستمی، فاصله هاورساین، تشخیص خودکار شهر، کارت «🎯 نزدیک‌ترین فروشگاه»، فیلتر شعاع تا ۵۰ کیلومتر.

**استان و شهر:** ۳۱ استان و ۴۱۳ شهر با مختصات. جست‌وجوی هوشمند با یکسان‌سازی نویسه — «كرمان» با ك عربی و «اسلام شهر» بدون نیم‌فاصله هم نتیجه می‌دهند.

**پیج فروشنده:** ثبت فروشگاه با ۲۲ دسته‌بندی، بیو، آیکون، ساعت کاری، موقعیت GPS دقیق. افزودن محصول با قیمت، واحد، تخفیف، توضیحات و مشخصات فنی خط‌به‌خط. شمارنده دنبال‌کننده.

**مقایسه:** رتبه‌بندی یک کالا در همه فروشگاه‌ها، نشان «🏆 بهترین قیمت»، خلاصه آماری و میزان صرفه‌جویی، هشدار «همین کالا ارزان‌تر هم هست!».

**داده نمونه:** فقط در حالت آفلاین (وقتی Supabase تنظیم نشده) ~۳۰۰ فروشگاه نمونه
ساخته می‌شود. در حالت آنلاین، داده‌های واقعی از سرور می‌آیند و نمونه‌ای تولید نمی‌شود.
